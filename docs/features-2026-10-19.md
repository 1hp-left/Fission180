Initial source was pushed to `1hp-left/Fission180` as `3a160c2`; implementation continued immediately. These are independently written Fission application features. No new Autodesk native algorithm is claimed recovered, and no complete Fusion command or visual parity is established.

## Implemented commands

All commands live in the core, replay in an explicit mixed timeline, preview through the geometry worker and use accepted edits/Undo/Redo. Desktop ribbon/menu entries now open working dialogs. Double-click edits stored features. Timeline context actions suppress/unsuppress or delete dependent commands. Named length parameters have an editor; Measure reports kernel volume, surface area and bounds.

| Capability | Executing backend | Current scope |
| --- | --- | --- |
| Revolve | OCCT | Planar region loops, principal axis, full/partial signed angle; creates a body. |
| Sweep | OCCT | Profile region along a connected open sketch line path; torsion orientation. No guide rails. |
| Loft | OCCT | Ordered planar section wires; core accepts 2–100 sections, desktop selects two. Inner loops rejected. |
| Hole | OCCT or explicitly selected Rust | Circular cut along world Z with explicit start, diameter and depth. Rust requires a supported through-cut; partial-depth curved cases fail explicitly. |
| Fillet / Chamfer | OCCT | Constant radius/distance on all body edges. Individual edge selector, variable radii and corner options remain absent. |
| Shell | OCCT | Inward thickness, removes the extreme planar face(s) on the selected principal side. Arbitrary faces/multiple thicknesses absent. |
| Press Pull | OCCT | True selected principal extreme planar face offset with adjacent geometry trimming/extension; not whole-body translation. |
| Move / Copy | OCCT or Rust | Translation in X/Y/Z. Rotation and scale are not included in this batch. |
| Rectangular Pattern | OCCT or Rust | Single principal direction, spacing and total quantity 2–100. Original plus independent copies. |
| Circular Pattern / Mirror | OCCT | Principal axis/plane; fixed origin at zero in desktop. Circular pattern avoids the duplicate endpoint for a full turn. |
| Combine | OCCT or scoped Rust Boolean | Explicit target/tool, Join/Cut/Intersect, optional Keep Tools; supports zero/multiple results. |
| Split Body | OCCT or scoped Rust Boolean | Explicit principal plane position. OCCT uses exact half-spaces; Rust uses its supported box intersection. |
| Face-based sketch | Application support relation, either backend | Principal extreme planar faces. Stores body/axis/side/offset, updates the sketch origin during replay. Arbitrary trimmed face attachment and persistent general topology naming remain absent. |

Unsupported Rust operations return an explicit error and preserve the previous document and display. Backend selection is persisted. OCCT remains the default; no implicit fallback or mesh-based modeling was introduced.

## History and persistence

New saves use version **3** of `openfusion-native`. Version 1 resolves its original profile indices before region migration; version 2 upgrades in memory. Reading does not overwrite the original. Version 3 adds mixed command order, command outputs, suppression and face support. Legacy version-1 serialization rejects extensions it cannot represent. Earlier executables cannot read v3.

Pattern quantity changes retain existing ordinal output IDs, allocate additional outputs with checked IDs, and reject changes that strand a downstream reference. Split/Boolean outputs have explicit stable body IDs. Dependent deletion and suppression use sketch, support and body dependencies. These are application identities and scoped support selectors, not complete persistent face naming.
